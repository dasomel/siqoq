## 문서 정책

핵심 문서는 영문/한국어를 함께 유지합니다. 영문은 국제 OSS 협업을 위한 canonical technical reference로 사용하고, 한국어 문서는 이해를 돕기 위한 설명을 추가할 수 있습니다. 단 interface, command, feature status, architecture decision은 두 언어에서 서로 모순되지 않아야 합니다.

빠르게 변하는 외부 생태계 리서치는 안정적인 architecture 문서와 분리해서 관리합니다. 외부 프로젝트의 변화가 Siqoq core design을 암묵적으로 바꾸지 않도록 하기 위함입니다.
